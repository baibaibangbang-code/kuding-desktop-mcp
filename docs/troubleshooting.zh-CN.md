# 常见问题与限制

## 安装目录有了，客户端仍连不上

先用安装目录的 Python 运行 `selftest.py`。自检失败时查看实际错误；不要用“进程存在”或“目录存在”作为完成依据。自检通过后再检查客户端配置的绝对路径、Python 路径、配置合并位置和 MCP 启动超时。冷启动可能比后续连接慢。

## 没找到控件

先确认窗口是否最小化、缩到托盘、锁屏，或者目标属于另一个弹窗。用 `Window(mode="list")` 枚举，再按窗口/进程范围查找。大型应用全桌面树可能慢或不完整。

部分 Electron 应用可能需要自身支持的无障碍启动选项，部分 Qt/WebView 界面只有空壳控件。应结合具体软件版本判断，转用 OCR/截图；不要把所有空树都归结为同一个原因。

## 截图能读，但点击落在别处

按窗口截图可能读取到被覆盖窗口的内容，但鼠标仍作用于实际屏幕上的最上层窗口。先置前，再刷新截图；严格按截图的比例和屏幕偏移换算。对截图产生的坐标使用支持的 frame 参数。frame 只检查窗口层面的归属，不能检查窗口内部所有内容变化。

## OCR 没读到，或识别错了

检查 Windows OCR 语言支持。缩小区域、检查对比度与字号，并观察返回的模糊匹配提示。OCR 空结果不等于目标不存在；OCR 文本也不适合单独作为精确输入验收的依据。

## 高权限窗口不接受输入

普通权限工具通常无法驱动更高完整性级别的窗口。UAC、安全桌面、密码和验证码由使用者处理。不要用反复点击或关闭保护设置来处理此问题。

## 别的程序抢鼠标，或按 Esc 后仍发生了一次动作

命名互斥体只协调采用相同机制的工具实例，其他自动化仍可能竞争桌面。真人输入会触发让路。Esc 的作用是中断后续动作，无法撤回已经发出的输入。遇到竞争先停止当前任务、确认桌面使用者。

## 本地日志与反馈

常规诊断输出在 MCP stderr。可设置 `UIA_DESKTOP_CALL_LOG` 写入本地文件；错误文本可能带窗口标题和路径。分享前逐项检查。不要上传客户资料、令牌、会话数据、未脱敏截图或完整业务目录。

提交 Issue 时说明 Windows/客户端/目标软件版本、工具与参数形状、预期/实际结果、复现步骤和已经尝试的处理方式。反馈由使用者主动提交，本项目不会自动上传日志。
