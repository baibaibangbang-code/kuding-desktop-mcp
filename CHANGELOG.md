# Changelog

## 0.6.0 — first public snapshot

- Published as **Kuding Desktop MCP** from the internal 0.6.0 code line, based on Windows-MCP 0.8.5.
- Retained scoped UIA inspection, local OCR, window-aware input checks, observation/wait tools, and desktop input coordination.
- Replaced internal installation/distribution and runtime-log feedback workflows with a standalone public installer, hashed pinned dependency snapshot, stdio launcher, and voluntary issue reporting.
- Kept the local-only replacement for upstream PostHog analytics and omitted the PostHog SDK.
- Added bilingual README files, the Chinese project article, client configuration, installation/maintenance, examples, limitations, third-party notices, and publication checks.
- Removed internal operational material and private history from this public snapshot. Existing internal deployments are not changed by this release.

See docs/validation.md for the actual release verification scope.
